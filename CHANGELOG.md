# Changelog

## 0.3.0 — 2026-09-02

- Never-again: ban a recipe immediately; it is swapped off this week and never planned again.
- Cooked / skipped flags on each meal (no need to have cooked it first).
- Household members, each with own kcal/protein.
- Mifflin–St Jeor calorie & protein calculator (sex, age, height, weight, activity, goal).
- 40 additional complete recipes (spices, numbered steps). Catalog now 85.

## 0.2.0 — 2026-09-02

- SemVer starts here (`v0.2.0`).
- Allergies / dislikes (“Ohne X”) in setup; planner skips matching recipes.
- Weekly budget is checkout (pack) cost, not raw recipe-line math.
- Week starts today, not always Monday.
- Meals can be locked; swap no longer changes them.
- After a swap, a link to the updated shopping list.
- Admin: weekly deals editor, user list, password reset, Pro toggle.
- Freemium: Free planner vs Pro (persistent cupboard + receipt scan).
- Pro: photograph a Kassenbon; matched items go into the cupboard.

## 0.1.0

- Invite-only Flask API + React app, ILP planner, pack-size shopping list.
